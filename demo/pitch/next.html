Next steps

1

Reject unknown gestures

Train with the dataset's other 198 signs as negatives so the model can answer "not a sign" instead of guessing.

2

Measure live, then fine-tune

Live WER with new signers in the app's evaluation mode, then fine-tune on a small set of real continuous signing.

3

Stronger model

Add face landmarks, try a Transformer or Conformer encoder, and repeat the ablation over several seeds.

4

Pretrained hybrid

The Kaggle 1st-place isolated recogniser names each sign our CTC model locates: 250 signs. Built, not yet scored on new signers.

5

Other languages

Translate glosses into Tamil, Hindi and Telugu with text-to-speech. Indian Sign Language by swapping the dataset in the same pipeline.
