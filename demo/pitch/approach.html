Approach

The public dataset has single signs only. We build the continuous sentences ourselves, then teach a sequence model to read them.

1 · Data

Google ASL Signs

250 isolated signs, 21 signers, MediaPipe landmarks already extracted. We keep 52 signs that combine into sentences: 19,590 clips.

2 · Split

By signer

15 signers train, 3 validate, 3 test. A test signer never appears in training, so word error rate measures generalisation to new people.

3 · Core idea

Sentence synthesis

2–5 clips from the same signer, joined with 3–8 interpolated transition frames, speed 0.8–1.25×. Half template sentences, half random orders. 20,000 new sentences per epoch.

4 · Features

Signer normalisation

Mirror so the dominant hand is on one side, centre on the shoulders, scale by shoulder width. Add velocity and a presence flag per hand.

Template example: mom drink water now · Random example: grandma like grandpa sleep · Output is gloss order, not English grammar

Four decisions. The data is ASL, not ISL, because it is the only public set with enough signers and ready landmarks for a credible held-out-signer test in 24 hours; the pipeline does not depend on the language. The split is by signer before anything else, and synthesis stays inside each split, so nothing leaks. Random sign orders stop the model from simply memorising the 16 template sentences.
